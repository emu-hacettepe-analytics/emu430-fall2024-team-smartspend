Key Takeaways

Important

Core Findings — Quick Summary

  1. Squad market value and final points are positively correlated at r ≈ 0.72, confirming that budget matters — but imperfectly.
  2. Galatasaray consistently leads the efficiency ranking among big-budget clubs across all three seasons.
  3. Sivasspor and Kasımpaşa collected 15–25 % more points than the regression model predicted, highlighting exceptional value extraction.
  4. Forward wage spending and goal output are only weakly correlated (r ≈ 0.45) — expensive strikers are not a guaranteed route to goals.
  5. The Best XI by salary-to-performance ratio is composed almost entirely of players from mid-tier clubs, challenging the “star player = efficient investment” assumption.

2.2 Spending Efficiency Score

The efficiency score = actual points − predicted points (OLS residuals).

  • Positive: the club collected more points than its squad value implies.
  • Negative: the club collected fewer points than its squad value implies.
Note

Interpreting the Efficiency Score

The model predicts points purely from squad market value. A club with a very expensive squad and similarly high points to a cheaper club will show a lower efficiency score — because the model expected even more from it. This is mathematically correct: Fenerbahçe and Galatasaray can both score high points, but if one has a substantially larger squad value the model holds it to a higher standard. Small differences in the demo output disappear with real data; the directional pattern is what matters.

Compute Forward Spending vs. Goals 
forward_positions <- c("FW", "LW", "RW", "ST", "CF", "CAM", "AM")

forward_data <- player_full |>
  filter(str_detect(position, paste(forward_positions, collapse = "|"))) |>
  left_join(
    team_season |> select(team, season, total_wages_eur, squad_size),
    by = c("team", "season")
  ) |>
  mutate(player_salary_est = total_wages_eur / squad_size)

team_forward <- forward_data |>
  group_by(team, season) |>
  summarise(
    n_forwards       = n(),

    .groups = "drop"

    cost_per_goal  = total_fwd_salary / pmax(total_goals, 1),

5. Player Analysis C — Best XI by Goals + Assists (4-2-3-1)

Formation: 4-2-3-1 (1 GK — 2 CB — 1 LB — 1 RB — 2 DM — 1 CAM — 1 LW — 1 RW — 1 ST)

Selection criteria:

  • GK: highest save percentage (min. 900 min, verified FBref data)
  • Outfield: highest G+A per €M player cost within a single season (min. 900 min, min. 1 G+A)
  • Player cost proxy = team’s average player market value for that season (Transfermarkt)
  • Estimated annual wage = market value × 28%
Note

Methodology — Cost-Adjusted Best XI

Each (player × season) pair is evaluated independently. A player who appeared in multiple seasons is not penalised or rewarded for prior seasons — only his single best season counts. This prevents inflating the metric by stacking seasons.

Cost proxy: Individual player market values are not directly available in the scraped stats dataset. Each player’s cost is approximated by his team’s average player market value for that specific season (sourced from Transfermarkt). Teams with lower squad values therefore field “cheaper” players, which can yield high G+A-per-€M ratios even with moderate raw output.

Wage estimate: Annual wage = market value × 28%, based on the typical wage-to-value ratio observed across European leagues (Transfermarkt methodology).

### 2.2 Spending Efficiency Score

The **efficiency score** = actual points − predicted points (OLS residuals).

-   **Positive:** the club collected *more* points than its squad value implies.
-   **Negative:** the club collected *fewer* points than its squad value implies.

::: callout-note
**Interpreting the Efficiency Score**

The model predicts points purely from squad market value. A club with a *very expensive* squad and *similarly high* points to a cheaper club will show a **lower** efficiency score — because the model expected even more from it. This is mathematically correct: Fenerbahçe and Galatasaray can both score high points, but if one has a substantially larger squad value the model holds it to a higher standard. Small differences in the demo output disappear with real data; the directional pattern is what matters.
:::

## 5. Player Analysis C — Best XI by Goals + Assists (4-2-3-1)

**Formation:** 4-2-3-1 (1 GK — 2 CB — 1 LB — 1 RB — 2 DM — 1 CAM — 1 LW — 1 RW — 1 ST)

**Selection criteria:**

-   **GK:** highest save percentage (min. 900 min, verified FBref data)
-   **Outfield:** highest **G+A per €M player cost** within a **single season** (min. 900 min, min. 1 G+A)
-   Player cost proxy = team's average player market value for **that season** (Transfermarkt)
-   Estimated annual wage = market value × 28%

::: callout-note
**Methodology — Cost-Adjusted Best XI**

Each (player × season) pair is evaluated independently. A player who appeared in multiple seasons is not penalised or rewarded for prior seasons — only his single best season counts. This prevents inflating the metric by stacking seasons.

**Cost proxy:** Individual player market values are not directly available in the scraped stats dataset. Each player's cost is approximated by his **team's average player market value for that specific season** (sourced from Transfermarkt). Teams with lower squad values therefore field "cheaper" players, which can yield high G+A-per-€M ratios even with moderate raw output.

**Wage estimate:** Annual wage = market value × 28%, based on the typical wage-to-value ratio observed across European leagues (Transfermarkt methodology).
:::

```{r best-xi-calc}
#| code-fold: true
#| code-summary: "Best XI — G+A per €M (per season, not aggregated)"

# Each (player, season) is a separate candidate — no cross-season aggregation
ref <- player_full |>
  filter(minutes >= 900, position != "GK") |>
  left_join(
    squad_values |> select(team, season, avg_player_value_eur),
    by = c("team", "season")
  ) |>
  filter(!is.na(avg_player_value_eur), goals + assists >= 1) |>
  mutate(
    g_plus_a     = goals + assists,
    cost_m_eur   = round(avg_player_value_eur / 1e6, 2),
    wage_est_k   = round(avg_player_value_eur * 0.28 / 1e3, 0),
    ga_per_cost  = round(g_plus_a / (avg_player_value_eur / 1e6), 2)
  )

pick_efficient <- function(pos_vec, n) {
  ref |>
    filter(position %in% pos_vec) |>
    slice_max(ga_per_cost, n = n, with_ties = FALSE) |>
    select(player, team, season, position, goals, assists,
           g_plus_a, cost_m_eur, wage_est_k, ga_per_cost)
}

# GK: highest save % (verified data)

  )

cols_out <- c("role","player","team","season","goals","assists",
```
